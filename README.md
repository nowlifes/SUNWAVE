# SUNWAVE

Find your perfect spot in the sun or shade. SUNWAVE maps sun and shadow patterns across Lisbon in real time, so you can discover the right place at the right time — whether you want to soak up the sun or escape it.

## Features

- **Live sun & shade map** — see which spots are sunny or shaded right now, with a time slider to preview conditions later in the day
- **Discover** — browse venues by category (cafes, parks, terraces, and more) filtered by sun/shade preference
- **Saved spots** — bookmark your favorite places for quick access
- **Profile & preferences** — customize your sun/shade mode and preferred categories
- **Directions** — one tap to open Google Maps navigation

## Tech

- React + TypeScript + Vite
- MapLibre GL for maps
- SunCalc for sun position calculations
- Tailwind CSS for styling
- Supabase for backend
